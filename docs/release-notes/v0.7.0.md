# AcornFox v0.7.0 发行说明

## 这一版是什么

这一版让从应用中心装的应用，装好以后也能管：改设置、升级、出问题退回、备份恢复；另外 Windows 电脑也能装了。

- **新的控制台**：左边四项——首页、我的应用、应用中心、设置。首页只放图表；要处理的事在铃铛和“我的应用”里。应用中心按“你想解决什么问题”摆解决方案，下面是全部应用；每个应用有一篇介绍、封面和一句话，解决方案可以按行业筛。
- **改设置后让它生效**：应用的“安装设置”里能改的项可以直接改，先告诉你会变什么、要不要重启，你同意了才做；不成功自动退回原来的样子。改了时区、下载源这类整台机器的设置，用到它的应用会提示“要跟上”，一键跟上。改谁能打开、加删域名以后，应用里的地址跟着变。
- **应用升级、退回**：应用中心有新版本时，“我的应用”和铃铛里会提示。点“更新”先看计划，升级前自动存一份快照；没升成功自动退回；升级后觉得不好，可以“退回到更新前”（会丢掉升级后新写的数据，这份数据另存着，至少留 7 天）。目录每 6 小时同步一次，打开应用中心时也会补一次。
- **备份和恢复**：应用设置里多了“备份”一行。立即备份、恢复、删除；恢复前先另存一份现在的数据，恢复不成功自动退回。
- **Windows**：一行 PowerShell 命令安装，在 WSL 里跑和 Linux 服务器同一个程序；没装 WSL 的电脑会帮你装上（要点一次管理员确认，可能要重启一次，重启后自动接着装）；局域网里的设备能打开；开机自己起来；`acornfox` 命令在 PowerShell 里直接用。
- **Mac**：一行命令安装（苹果芯片、macOS 26 起），整套 Linux 版装进苹果 container 开的 Debian 虚拟机，Mac 本机只放一个小的常驻程序；局域网里的设备能打开；30 分钟没人用就把虚拟机停掉省内存，有人访问时 1～2 秒自动叫起；`acornfox` 命令在 Mac 终端里直接用。
- **应用的操作手册**：应用中心里的应用和解决方案可以带一份操作手册（装前要问什么、装好怎么用起来、常见问题）。应用页多了“让 AI 帮我装”，点了复制一段话给你的 AI 工作台，它会先取手册再照着做。
- **AI 工作台知道这台机器能做什么**：`acornfox machine` 列出装了哪些应用、各能做什么、能提供哪些服务（不含密码和 Key）；`acornfox skill install` 时在 Skill 里写一份，装删应用后自动更新。
- **Skill 拆成入口加分册**：AI 工作台先读一个很短的入口，再按要办的事只读需要的那一册；`acornfox capabilities` 列出这个版本的全部命令和故障编号。
- **装得更快、更稳**：中国大陆的机器装应用不再去连 Docker Hub，只用国内镜像源；大的镜像包经我们的下载网关分段、多路同时下载，断了能接着下，下完核对校验值；Gitee 下载中途卡住先在 Gitee 重试一次。
- **其他**：
  - 安装应用时可以选谁能打开（只本机 / 局域网 / 公网）；下载时显示已下多少、多快、还要多久。
  - 数据库这类只给别的应用用的应用，详情页不再给不适用的设置。
  - 登录页多了“忘了密码”，告诉你在服务器上怎么重设，或一段可以直接交给 AI 工作台的话。
  - 电脑上的 `acornfox` 命令行比服务器旧时，每天提醒一次怎么更新；`acornfox doctor` 会查已装的 Skill 是不是旧的。

升级（Linux 服务器）：

```bash
# 中国大陆
curl -fsSL https://gitee.com/VIP13390/AcornFox/raw/main/get.sh | sudo bash -s -- upgrade
# 其他地区
curl -fsSL https://github.com/OrbitMaker/AcornFox/releases/latest/download/get.sh | sudo bash -s -- upgrade
```

## 升级前请看（已知影响）

- 控制台左侧菜单改成四项，“运行环境”里的体检挪到了“设置 › 这台机器”。
- Skill 变成一个目录（入口加分册）：已经装过 Skill 的，运行一次 `acornfox skill install` 换成新的；`acornfox doctor` 会提醒。
- 改谁能打开、加删域名时，如果应用里用到了自己的地址，会先问你要不要重启它（命令行要加 `--yes`，或 `--no-reapply` 只改访问方式、稍后再让应用跟上）。按老办法直接调接口的脚本会收到 409，需要带上确认。
- 中国大陆的机器默认不再试 Docker Hub、ghcr.io 本身；机器能直连它们（例如有代理）的，可以用 `ACORNFOX_REGISTRY_MIRRORS`、`ACORNFOX_GHCR_MIRRORS` 加回来。
- 备份文件放在数据目录下，会占磁盘；手动备份默认留 5 份。
- 升级时 AcornFox 服务停几秒，这几秒控制台打不开，应用不受影响。还在用 v0.5.1 及更早版本的，先看 [v0.6.0 的发行说明](v0.6.0.md) 里的“升级前请看”。

## 支持哪些平台、怎么安装

- Linux 服务器（amd64、arm64）：和 v0.6.0 一样，见 [v0.6.0 的发行说明](v0.6.0.md)。
- Windows 10/11（x64，要能开虚拟化）：见 README 的 Windows 一节。
- Mac（苹果芯片、macOS 26 起）：见 README 的 Mac 一节。

指定装这一版：在安装命令后面加 `-s -- --version v0.7.0`。

## 这一版测了什么、没有测到什么

测了：

- 全新安装、从旧版本升级两条回归路径；中国大陆网络下装应用不碰被屏蔽的站点。
- 一个应用从上架到用户手里、再到升级的整条路，以及一个解决方案一次装好。
- 改设置生效、改时区后跟上、改谁能打开后地址跟着变、坏设置自动退回；升级、手动退回、坏版本自动退回；备份、恢复、恢复失败自动退回。
- Windows 11：有 WSL 和没有 WSL 两种起点从零安装、局域网访问、重启后恢复、保留数据卸载和全部删除；经下载网关下载 WSL 安装包和 Debian、Ubuntu 镜像。
- 只凭 Skill 让较弱的 AI 模型走装应用、改设置、备份、升级、退回、恢复、忘了密码和 Windows 安装；拆成分册以后又走了一遍，每一步只读入口加一册。
- Mac：在一台真 Mac 上从没有虚拟机装起、闲置停机和叫起、升级、卸载和重装。

没有测到：

- Windows：管理员密码那条路（只测了点“是”“否”）、普通账号、Windows 10、ARM 版。
- Mac：第一次装苹果 container 和内核那两步（测试用的 Mac 早就装好了）、真的重启 Mac；Intel 芯片的 Mac 和 macOS 26 以下不支持。
- 应用操作手册：让 AI 照手册走的验证，目前是在测试机上跑手册里的确认命令，还没让较弱的模型照手册从头走。
- 家里宽带下经下载网关下载大文件的实际速度（只在限速代理下测了分段下载的效果）。
- 手机宽度和深色下的全部页面（只截了主要页面）。
