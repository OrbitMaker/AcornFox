# AcornFox v0.6.3 发行说明

## 这一版是什么

这一版只改网页控制台和几处说明文字，让“应用之间怎么连着”“应用是用什么装起来的”在页面上看得见。服务端的装、升级、对外访问的做法和 v0.6.2 一样。

- **设置 › 服务，改成一行一项**：每条服务一行，一句话写谁提供、谁在用，点开才看细节（各项的值、试一下、能不能删）。原来的功能都在。
  - 最后多一行“平台自动填的”：时区、下载源这几项，装应用时平台替你填好的值，点开能看。
- **应用概览多一张“连接”卡片**：一行一句，写这个应用用着谁的服务（例如“数据库用的是 postgres16 的”），或者谁在用它的服务（这时也说明为什么现在不能删它）。没有连接的应用不显示这张卡片。
- **应用设置多一行“安装设置”**（只有从应用中心装的应用有）：这个应用是用哪些值装起来的。
  - 收起时一句话；装的时候的值和现在算出来的不一样时（例如装好后改了谁能打开），带黄点提醒。
  - 点开只列你自己填的和它连着谁；其余的收在“全部显示”里，分“平台填的”和“自定义的”两组。密码和 Key 只显示后几位，点“显示”才看完整的。
  - 只能看，还不能在这里改。
- **在页面上开启公网控制台以后，不再让人白跑一趟**：第一次开启时要现申请证书，通常一两分钟，这段时间打开地址浏览器会报“连接不安全”。现在开启后页面先写“正在申请证书”，好了自己变成“可以打开了”；几分钟还没好会说明服务器还在重试。

另外：

- 说法统一：平台给的那几项以前有的地方叫“系统变量”，现在都叫“平台变量”（命令行帮助、Skill、`acornfox apps vars` 的输出）。其余的都叫自定义变量，分应用自己的设置和服务。
- `GET /v1/public-console?check=https`：开着时多返回一项 `https`，是服务器自己查的证书状态（`ok`、`cert_pending`、`cert_failed`，别的诊断码表示这台服务器确认不了）。不带这个参数时和以前一样。

升级：

```bash
# 中国大陆
curl -fsSL https://gitee.com/VIP13390/AcornFox/raw/main/get.sh | sudo bash -s -- upgrade
# 其他地区
curl -fsSL https://github.com/OrbitMaker/AcornFox/releases/latest/download/get.sh | sudo bash -s -- upgrade
```

## 升级前请看（已知影响）

- **应用概览最下面原来的“用到的服务”卡片没有了**，它说的事并进了“连接”卡片。“连接”只列已经接上的；可选的、装的时候没接上的服务不再在概览里列出来，用 `acornfox status 应用名` 看。服务不能用时，概览最上面的提醒照旧。
- **“安装设置”里看不到接上的服务给的地址、账号、密码**，只写它连着谁。要看这些值，到“设置 › 服务”里点开那条服务（按每个应用单独发的账号这一版页面上看不到）。
- **`acornfox apps vars` 的输出里，层的中文名从“系统变量”变成了“平台变量”**（`--json` 里的 `layer_label` 也跟着变）。给程序读的 `layer` 值（`system`、`custom`）没变；按中文名匹配的脚本要改。
- **证书好了没有，是服务器连自己的公网地址查的。** 有的云不允许服务器这样连自己，这时页面会照实写“这台服务器自己确认不了”，过一两分钟直接打开地址试试。
- 升级时 AcornFox 服务停几秒，这几秒控制台打不开，应用不受影响。从 v0.6.0 起的版本升上来不会再换入口容器。
- 还在用 v0.5.1 及更早版本的，升级前先看 [v0.6.0 的发行说明](v0.6.0.md) 里的“升级前请看”。

## 支持哪些平台、怎么安装

和 v0.6.0 一样，见 [v0.6.0 的发行说明](v0.6.0.md)。指定装这一版：在安装命令后面加 `-s -- --version v0.6.3`。

## 这一版测了什么、没有测到什么

测了：

- 全新安装和从旧版本升级两条回归路径。
- 在一台装了数据库和用它的应用的测试机上，打开真实页面看过三处：设置里的服务、应用概览的“连接”、应用设置的“安装设置”（含改了谁能打开以后的提醒）。
- 在一台有公网地址的云主机上用真域名看过证书提示的三种状态：申请中、几分钟还没签下来、签下来以后自己变成可以打开。

没有测到：

- “安装设置”里几项一起不一样时并成一个提示的样子，只有自动测试，没有在真实页面上看。
- 自己登记的服务被应用用上以后，“连接”卡片的那一行，只有自动测试。
- 服务很多（十几条）时服务页的样子；有的云上“服务器确认不了证书”的那句提示。
- Mac、Windows 上的浏览器；手机宽度下的排版。
