# AcornFox v0.6.1 发行说明

## 这一版是什么

这一版只改网页控制台，修掉 v0.6.0 里的一个页面问题，并把应用详情页重新整理了一遍。服务端、命令行、安装和升级的做法都和 v0.6.0 一样。

- **修复：数据库这类应用的详情页打不开。** v0.6.0 里，从应用中心装的、只在内部网络的应用（PostgreSQL、MySQL、Redis 这类没有网页的），在控制台里点开详情会整页空白。这一版修好了。用 v0.6.0 的建议升级。
- **应用详情页重新整理**：页签从七个收成四个——概览、日志、版本、设置。
  - 名片只留名字、一句话状态、“打开”和一个“更多”菜单（重启、停止在里面）。
  - 概览最上面是“访问”：地址、复制地址、手机扫码，以及“只本机、局域网、公网”三档。三档可以直接点；改成公网前会先确认。从应用中心装的应用，首次登录的账号密码也在这里。
  - 概览下面是三张图：近 30 天的运行条、CPU 和内存各用了上限的多少、版本时间线。
  - 原来的“配置、数据、资源、高级”四个页签并成“设置”一页，一行一项，点开才展开：谁能打开（含域名）、资源上限、数据、更多（环境变量、端口和健康检查、常用命令），最下面是删除应用。
- **页面名只写一次**：首页、我的应用、应用中心、运行环境、设置这几页，页面里重复的大标题去掉了，数量、状态和页面自己的按钮挪到了顶栏。

升级：

```bash
# 中国大陆
curl -fsSL https://gitee.com/VIP13390/AcornFox/raw/main/get.sh | sudo bash -s -- upgrade
# 其他地区
curl -fsSL https://github.com/OrbitMaker/AcornFox/releases/latest/download/get.sh | sudo bash -s -- upgrade
```

## 升级前请看（已知影响）

- **应用概览里不再有内存、CPU 的曲线图。** 概览里的圆环显示的是现在的用量；要看一段时间的走势，用命令行：`acornfox stats 应用名 --history 1h`（或 `24h`）。首页上整台机器的曲线照旧。
- **以前收藏的页签地址仍然能用。** 原来直接打开“配置、数据、资源、高级”的地址，会落到“设置”并展开对应的那一项。
- **运行条说的是“这次启动以来连续运行了多久”。** 平台还不记每天有没有中断过，所以启动以前的格子是空的，不代表那几天出过问题。
- **“设置”里某一项改到一半没保存，收起再展开，改动会丢。** 改完先点保存。
- 升级时 AcornFox 服务停几秒，这几秒控制台打不开，应用不受影响（和 v0.6.0 一样）。从 v0.6.0 升上来不会再换入口容器。
- 还在用 v0.5.1 及更早版本的，升级前先看 [v0.6.0 的发行说明](v0.6.0.md) 里的“升级前请看”：那一版换了应用清单的格式、安装命令和入口容器，这些变化在跨过 v0.6.0 时一样会发生。

## 支持哪些平台、怎么安装

和 v0.6.0 一样，见 [v0.6.0 的发行说明](v0.6.0.md)。指定装这一版：在安装命令后面加 `-s -- --version v0.6.1`。

## 这一版没有测到的

- Mac、Windows 上的浏览器没有逐个看过；手机宽度（小于 768 像素）下的排版没有看过。
- “手机扫码”没有用真手机扫过。
- 新入口代理下用真域名申请证书，仍然没有实测（和 v0.6.0 一样）。
