# AcornFox v0.5.0 发行说明

## 这一版是什么

这一版加了应用中心：从预先配好的目录在 Linux 服务器上装应用，不用写 Dockerfile，也不用自己想密码。首批是 New API（大模型接口网关）和 Hermes 智能体，以及 3 个配方。控制台换成了新版，AcornFox 平台改成只能升级。

## 支持哪些平台

| 平台 | 本版提供的程序 | 说明 |
| --- | --- | --- |
| Linux x86_64（amd64） | 服务端 + 命令行 | 正式支持。Ubuntu 22.04、24.04，Debian 12、13；推荐 Ubuntu 24.04 或 Debian 13 |
| Linux arm64 | 服务端 + 命令行 | 安装脚本允许安装，但**还没有实测** |
| macOS（Apple 芯片、Intel） | 只有命令行 | 在 Mac 上装命令行，经 SSH 管理 Linux 服务器。本版不提供在 Mac 本机运行 AcornFox 服务端，在 Mac 上运行不带应用名的 `acornfox install` 或 `acornfox doctor` 只会提示还不能用（`SETUP-MAC-01`） |
| Windows | 不提供 | 用 SSH 登录服务器，在服务器上运行 `acornfox`，做法见 [使用手册](../user-guide.md#windows-电脑经-ssh-在服务器上操作) |

建议配置：2 核 2 GB 以上；需要 root 或 sudo。要装 Hermes 智能体，内存建议再留出 2 GB，磁盘至少留 6 GB。

## 安装

在 Linux 服务器上运行（按服务器所在网络选一条）。

中国大陆：

```bash
curl -fsSL https://gitee.com/VIP13390/AcornFox/raw/main/scripts/install/install.sh | sudo bash
```

其他地区：

```bash
curl -fsSL https://github.com/OrbitMaker/AcornFox/releases/latest/download/install.sh | sudo bash
```

用 AI 工作台安装，把下面这句话发给它：

```text
请安装 AcornFox Skill：下载 https://acornfox.com/skill/SKILL.md ，保存为你 skills 目录下的 acornfox/SKILL.md（Claude Code 是 ~/.claude/skills，Codex 是 ~/.codex/skills），然后按这个 Skill 把当前项目部署到我的服务器。
```

## 新功能和改进

### 应用中心

- **目录**：

  | 应用或配方 | 是什么 |
  | --- | --- |
  | `new-api` | New API：把多家大模型合成一个 OpenAI 兼容的接口，统一管理上游 Key、令牌和额度。约 1 分钟装好 |
  | `hermes-agent` | Hermes 智能体：常驻的 AI 智能体，可以接飞书、钉钉、企业微信等做机器人。约 3～4 分钟装好 |
  | 配方 `hermes-with-new-api` | 两个一起装并连起来，Hermes 经本机 New API 用大模型 |

  另有只装 New API、只装 Hermes 的两个配方。两个应用都是上游原版镜像，单容器。
- **两种装法**：控制台左侧“应用中心”，选应用点“安装”；或者命令行 `acornfox install new-api`、`acornfox install --recipe hermes-with-new-api`。`acornfox catalog list`、`catalog info` 看目录和参数。
- **装之前检查**：内存（`CAT-INST-05`）和磁盘剩余空间（`CAT-INST-27`）不够时停下，不会装一半。装失败时这次新建的应用和数据卷自动清理。
- **密码由平台生成**：装好后给出首次登录信息，密码默认遮住，页面上点显示，命令行用 `acornfox install status 任务编号 --show-secrets`。
- **New API 装好即初始化**：New API 第一次打开时谁先打开谁当管理员，AcornFox 在装好后立刻替你完成初始化，并关掉自助注册。
- **Hermes 接本机 New API**：选 `--llm local`（或装配方）时，AcornFox 在 New API 里建一把令牌交给 Hermes。这把令牌不限额、不过期，安装完成页和应用详情里会提示：要控制花费，可在 New API 的“令牌”页设上限。删除 Hermes 时顺带吊销这把令牌。
- **安装进度**：每一步都有状态和说明。命令行等待时每 10 秒打印一次进度。
- **大镜像经下载网关下载**：Hermes 的镜像约 1.1 GB，只在 Docker Hub 上。AcornFox 先从下载网关 `dl.acornfox.com` 要临时地址下载我们存好的镜像包，进度里显示已下多少、速度和预计剩余时间；中途断开、超时或地址过期时从已下的位置接着下；下完按目录里签名的校验值核对。网关没成功时改从公共镜像源拉，并写明原因。
- **平台变量**：时区、Python 和 Node 包下载源、默认对话模型由平台按这台机器填进应用；`acornfox catalog platform-vars` 查看，安装时可以用 `--set platform.名字=值` 改能改的几项。
- **接上旧数据重装**：删除应用默认保留数据卷。用同一个名字再装时默认会停下（`CAT-INST-24`）；页面上点“接上旧数据重装”，或命令行加 `--reuse-data`，就接着用旧数据，账号密码和以前一样。
- **目录同步**：服务器每天同步一次目录（`acornfox.com/catalog`，打不开时读 Gitee 上的备用副本），文件带签名，签名对不上的不用。都取不到时用程序自带的目录。

### 只本机的应用怎么打开

从应用中心装的应用默认只听服务器本机地址，不用去安全组放行端口：

- **公网服务器**：在你自己的电脑上运行 `acornfox open 应用名`，它像打开控制台一样开一条 SSH 隧道，看完按 Ctrl+C 关闭。
- **服务器在你的局域网里**：页面上点“让局域网里的电脑能打开”，确认后用应用卡片上的“打开”按钮或 `http://服务器的局域网地址:端口` 打开。确认框写明这会在服务器所有网卡上开放这个端口。云服务器上不显示这个按钮。
- `acornfox apps` 和“我的应用”里，只本机的应用标“只本机”，地址显示 `127.0.0.1`。

### 新控制台

- 控制台换成新版，入口不变（`acornfox open`），分为首页、我的应用、应用中心、运行环境、设置。
- 首页看板：整机 CPU、内存、磁盘和应用状态，布局可以自己调。整机资源历史只保存在内存里，最多 24 小时，后台服务重启后重新记。
- 运行环境：服务、Docker、网址入口（Caddy 容器）、磁盘、端口、时钟的自检结果，每项带故障编号和处理办法。
- 设置里的“升级”只给升级命令。
- 旧控制台已经去掉，旧地址 `/legacy/` 会跳到新控制台。

### 只能升级

- AcornFox 平台本身只能升级，不能回到旧版本。升级脚本去掉了 `--rollback`（用了报 `UPGRADE-ROLLBACK-01`）；`--version` 指定更旧的版本会被拒绝（`UPGRADE-DOWN-01`）；用 `install.sh` 在已装好的服务器上装更旧的版本、或卸载时保留了数据后再装更旧的版本，也会被拒绝（`INSTALL-DOWN-01`）。都在停服务之前停下，什么都不改。
- 升级没成功时自动恢复到升级前：数据库迁移失败、新版本服务起不来、升级中途出错，包括被 Ctrl+C 打断、SSH 断开，都会把程序和数据库换回原来的。恢复过程不响应中断，另记在 `/var/log/acornfox-upgrade.log`。
- 应用自己的版本回退不受影响，照常用 `acornfox rollback 应用名`。

### 时钟检查

- `acornfox doctor` 和控制台“运行环境”新增时钟检查（`SETUP-CLOCK-01`）：看系统有没有开网络对时，并和下载网关的时间比对。差 300 秒以上时下载网关会拒绝请求，按提示运行 `sudo timedatectl set-ntp true`。AcornFox 不改系统时间。
- 下载网关因为时钟不准拒绝请求时，AcornFox 会按网关的时间重新签名一次；还不行就在错误里写明差了多少秒。

### 其他修复

- `acornfox delete 应用名` 按写的应用名删除（v0.4.0 会按当前目录对应的应用删）；应用名和 `--app` 不一致时拒绝。v0.4.1 已带这项修复。
- 国内安装（`--china`）不再去 GitHub 取 Caddy 的校验文件，校验值写在脚本里。v0.4.1 已带这项修复。
- 服务启动时的镜像源自检，只在前面的镜像源都不通时才探测 Docker Hub 官方地址。

## 从 v0.4.x 升级

在服务器上运行（按服务器所在网络选一条）。

中国大陆：

```bash
curl -fsSL https://gitee.com/VIP13390/AcornFox/raw/main/scripts/install/upgrade.sh | sudo bash
```

其他地区：

```bash
curl -fsSL https://github.com/OrbitMaker/AcornFox/releases/latest/download/upgrade.sh | sudo bash
```

- 管道运行就视为同意升级；已经是最新版本时直接退出，不停服务。只有要重装同一版本时才加 `-y`。
- 升级前把程序和数据库备份到 `/var/lib/acornfox/backups/`（保留最近 5 份），再做数据库迁移；应用容器一直运行，升级期间命令行和控制台会暂时连不上。
- **升级到 v0.5.0 之后不能再回到 v0.4.x。** 升级没成功时会自动恢复到升级前，不需要手动回滚。
- 升级后 `acornfox open` 打开的是新控制台，旧控制台已经去掉。
- 先升级服务器，再升级自己电脑上的命令行（重新运行一次安装命令行的命令）。应用中心的命令要服务器也是 v0.5.0 才能用。
- 从 v0.4.1 升级到 v0.5.0 实测过：已有的应用、版本记录和数据都在。

## 已知限制

- **应用升级**：这一版没有把已装的应用升级到目录里的新版本。要换新版本，先 `acornfox delete 应用名`（默认保留数据），再用原来的安装命令加 `--reuse-data` 重装。新版本能不能读旧数据由应用自己决定。
- **私有目录**：这一版不开放。
- **平台 Key**：这一版不能用（`CAT-INST-09`），大模型请用本机 New API 或自己的 Key。
- **Hermes 智能体**：安装约 3～4 分钟，主要花在下载和导入镜像上。上游程序启动时会访问 `nousresearch.github.io`（取能力目录），国内网络打不开，不影响对话。要求大模型的上下文不少于 64K。
- **Hermes 用的令牌不限额**：经本机 New API 时发给 Hermes 的令牌不限额、不过期，请在 New API 里自己设上限。
- **关掉下载网关后**：Hermes 的镜像改从公共镜像源拉，国内会慢很多，有时拉不下来。
- **arm64 Linux**：程序照常发布，安装脚本也允许，但还没有实测过；应用中心的两个应用也没在 arm64 上装过。
- **Windows**：本版不提供程序，在服务器上直接用 `acornfox`。
- **Mac 本机运行**：本版不提供，Mac 上只能装命令行。早先用开发版在 Mac 上试装过本机服务的，运行一次 `acornfox uninstall` 清掉开机自启（默认保留数据）。
- **Mac 命令行**：程序没有 Apple 开发者签名；用安装命令安装不会被 Gatekeeper 拦，自己用浏览器下载程序时可能会被拦。
- **首页看板**：只放有数据来源的图表；网络流量、7 天历史等还没有。

## 联网和隐私

AcornFox 没有使用统计，也没有崩溃上报。这一版新增了两处会联系 AcornFox 服务器的地方：

- **下载网关 `dl.acornfox.com`**：从应用中心装 Hermes 时用。第一次用时登记一个随机生成的机器编号和公钥，以及程序版本、系统和 CPU 架构；之后每次要下载地址时带签名。不读硬件信息，不发应用列表、项目代码、日志和密码。网关能看到服务器的 IP。
- **应用目录**：每天从 `acornfox.com/catalog` 同步一次，打不开时读 Gitee 上的备用副本。这是普通的下载请求，不带机器编号。

另外，`acornfox doctor` 和控制台“运行环境”页的时钟检查会向下载网关发一个 HEAD 请求，只读服务器时间。

下载网关可以关掉（`/var/lib/acornfox/network.json` 写 `{"gateway": "off"}`，或环境变量 `ACORNFOX_GATEWAY` 设为空值）；目录来源可以用 `ACORNFOX_CATALOG_SOURCES` 换成自己的副本。具体发了哪些字段、怎么关、关了会怎样，以及安装和运行时访问的全部地址，见 [使用手册的“隐私和联网说明”](../user-guide.md#隐私和联网说明)。

## 发行文件

| 文件 | 用途 |
| --- | --- |
| `acornfox_linux_amd64`、`acornfox_linux_arm64` | Linux 服务端和命令行 |
| `acornfox_darwin_arm64`、`acornfox_darwin_amd64` | Mac 命令行（Apple 芯片、Intel） |
| `install.sh`、`upgrade.sh`、`uninstall.sh` | Linux 服务器的安装、升级、卸载脚本 |
| `install-cli.sh` | 在自己电脑上安装命令行 |
| `SHA256SUMS` | 上面 `acornfox_*` 程序的 SHA256 校验值 |
| `caddy_2.8.4_linux_amd64.tar.gz`、`caddy_2.8.4_linux_arm64.tar.gz`、`caddy_2.8.4_checksums.txt`、`caddy_LICENSE` | Caddy 官方安装包、校验文件和许可证（Apache-2.0），供中国大陆安装时从 Gitee 下载 |

安装脚本会自动校验。手动下载程序后，在同一目录里核对：

```bash
sha256sum -c SHA256SUMS --ignore-missing
```
