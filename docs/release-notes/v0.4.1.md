# AcornFox v0.4.1 发行说明

修复版，只改两处，建议所有 v0.4.0 用户升级。支持的平台、系统和用法都和 [v0.4.0](v0.4.0.md) 一样。

## 修了什么

### `acornfox delete 应用名` 会删错应用

v0.4.0 里，`acornfox delete` 忽略写在后面的应用名，改为删除当前目录对应的应用。例如在 `api` 项目的目录里运行 `acornfox delete web`，删掉的是 `api`。数据卷默认保留，但容器和应用记录会被删掉。

现在 `delete` 和 `rollback`、`logs` 一样认命令行里的应用名；同时写了 `--app` 且两者不一致时拒绝执行。`acornfox delete --help` 有中文说明。

如果你在 v0.4.0 上误删过应用：数据卷默认还在（`docker volume ls` 能看到以 `af-` 开头的卷），先不要清理它们，也不要用 `--purge` 卸载。

### 国内安装（`--china`）仍会访问 GitHub

v0.4.0 的安装脚本在国内路径下也会先去 GitHub 取 Caddy 的校验文件，GitHub 不通时要等超时才改用镜像。现在 Caddy 2.8.4 官方发布的 SHA-512 校验值直接写在脚本里，安装包仍从国内镜像下载并按这个值校验，国内安装全程不再访问 GitHub。

## 怎么升级

在服务器上运行：

```bash
curl -fsSL https://gitee.com/VIP13390/AcornFox/raw/main/scripts/install/upgrade.sh | sudo bash
```

境外服务器用：

```bash
curl -fsSL https://github.com/OrbitMaker/AcornFox/releases/latest/download/upgrade.sh | sudo bash
```

升级只换程序，不动应用和数据；Mac 上的命令行客户端用 `install-cli.sh` 重新装一次即可。
