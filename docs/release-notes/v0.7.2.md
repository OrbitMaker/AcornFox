# AcornFox v0.7.2 发行说明

## 这一版是什么

安装命令可以带一个来源标记，用来知道哪个视频、文章里的链接带来了多少台安装。别的功能没变。

- **安装命令可以带来源标记**：如果你是从某个视频、文章里的链接点进官网、再复制安装命令的，命令末尾可能多了一段 `--from 某个名字`（Windows 是 `-From 某个名字`）。装好后，AcornFox 会把这个名字向 AcornFox 的下载网关报一次，**只报这个名字**，我们用它来知道哪个链接带来了多少台。没带这一段的安装和以前完全一样，不会因此联系下载网关。升级、卸载不用它。
- **不想报**：把命令末尾那一段删掉再运行；已经装好、还没报的，删掉服务器上的 `/var/lib/acornfox/install-from` 文件，或给后台服务设环境变量 `ACORNFOX_INSTALL_FROM=off` 后重启。详细说明见官网的“隐私和联网说明”。

升级（Linux 服务器）：

```bash
# 中国大陆
curl -fsSL https://gitee.com/VIP13390/AcornFox/raw/main/get.sh | sudo bash -s -- upgrade
# 其他地区
curl -fsSL https://github.com/OrbitMaker/AcornFox/releases/latest/download/get.sh | sudo bash -s -- upgrade
```

Windows、Mac 的升级命令见 README 对应的一节。

## 升级前请看（已知影响）

- 这一版的安装脚本多认一个 `--from` 选项，老版本的脚本不认它；用 `--version` 指定装老版本时，引导脚本会自动不传这个选项。
- 升级时 AcornFox 服务停几秒，这几秒控制台打不开，应用不受影响。从 v0.6.x 升上来的，先看 [v0.7.0 的发行说明](v0.7.0.md) 里的“升级前请看”。

## 支持哪些平台、怎么安装

和 v0.7.1 一样：Linux 服务器（amd64、arm64）、Windows 10/11（x64）、Mac（苹果芯片、macOS 26 起），见 README。

指定装这一版：在安装命令后面加 `-s -- --version v0.7.2`。

## 这一版测了什么、没有测到什么

测了：

- 安装脚本：带和不带 `--from`、标记不合规、和别的选项一起用、指定老版本时不传、Mac 传进虚拟机，脚本测试全过；Linux 全新安装和升级回归见发布工具的候选检查。
- 报标记：没标记不报、有标记报一次、重启不重复、网关没记下时重试、7 天后放弃，单元测试全过；下载网关一侧的登记和统计做了端到端演练。

没有测到：

- Windows：入口脚本只做了静态检查和文件核对，没在 Windows 上真装。
- Mac：只做了单元测试和脚本测试，没在真 Mac 上重装。
